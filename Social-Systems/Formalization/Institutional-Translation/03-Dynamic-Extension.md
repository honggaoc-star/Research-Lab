# Dynamic Extension

## Recursive Institutional Translation and the Evolution of Social Outcomes

**Repository**

`Research-Lab/Social-Systems/Formalization/Institutional-Translation/03-Dynamic-Extension.md`

**Status**

Working Draft

**Phase**

VI — Formalization

**Purpose**

To extend the static Institutional Translation model into a recursive dynamic structure in which translated outcomes affect future actor characteristics, allocations, behavior, institutional implementation, and eventually the translation function itself.

---

# 1. Purpose of the Dynamic Extension

The baseline Institutional Translation model describes how institutions condition the relationship between actor characteristics and outcomes:

[
Y_{i,t+1}
=========

\Phi_t(h_{i,t};I_t,E_t)
+
\varepsilon_{i,t+1}.
]

In the static model, the translation function is treated as fixed over the period of analysis.

That assumption is useful for identifying the mechanism, but it is incomplete.

Social outcomes may alter:

* future actor characteristics;
* resource distributions;
* political influence;
* behavioral strategies;
* institutional enforcement;
* administrative capacity;
* the design of future institutional rules.

Institutional Translation may therefore operate recursively.

The central dynamic question is:

> How do outcomes generated by an institutional translation process alter the future conditions under which translation occurs?

The objective is not to construct a complete dynamic theory of society.

The objective is to identify the smallest recursive structure needed to represent persistence, amplification, compression, adaptation, and institutional change.

---

# 2. Static Baseline

The static baseline is:

[
Y_{i,t+1}
=========

\alpha
+
\beta h_{i,t}
+
\gamma I_t
+
\delta h_{i,t}I_t
+
\lambda^\top E_t
+
\varepsilon_{i,t+1}.
]

The characteristic gradient is:

[
\frac{\partial Y_{i,t+1}}
{\partial h_{i,t}}
==================

\beta+\delta I_t.
]

The translation coefficient:

[
\delta
]

indicates whether the institutional environment changes the return to the actor characteristic.

In the static model:

* (h_{i,t}) is predetermined;
* (I_t) is given;
* (\Phi_t) is fixed;
* (Y_{i,t+1}) is the generated outcome.

The dynamic extension relaxes these assumptions sequentially.

---

# 3. Dynamic Architecture

The minimum recursive structure contains four relationships:

## Translation

[
Y_{i,t+1}
=========

\Phi_t(h_{i,t};I_t,E_t)
+
\varepsilon_{i,t+1}.
]

## Characteristic Updating

[
h_{i,t+1}
=========

\mathcal{H}
\left(
h_{i,t},
Y_{i,t+1},
I_t,
E_t
\right)
+
\nu_{i,t+1}.
]

## Allocation Formation

[
A_{t+1}
=======

\mathcal{G}
\left(
Y_{1,t+1},
\ldots,
Y_{n,t+1}
\right).
]

## Institutional Updating

[
I_{t+1}
=======

\mathcal{I}
\left(
I_t,
A_{t+1},
B_{t+1},
P_{t+1},
L_t,
E_t
\right)
+
\omega_{t+1}.
]

Together, these relationships form the recursive sequence:

[
(H_t,I_t,E_t)
\rightarrow
Y_{t+1}
\rightarrow
(H_{t+1},A_{t+1},B_{t+1},P_{t+1})
\rightarrow
I_{t+1}.
]

The updated institution then conditions translation in the next period.

---

# 4. Minimum Dynamic State

The static Institutional Translation model used:

[
S_t^{IT}
========

(H_t,I_t,E_t).
]

The minimum dynamic extension requires allocation:

[
S_t^{DIT}
=========

(H_t,I_t,A_t,E_t).
]

This state is sufficient when institutional updating depends only on prior allocation and external conditions.

A richer version may include:

[
S_t^{DIT+}
==========

(H_t,I_t,A_t,B_t,P_t,L_t,E_t),
]

where:

* (B_t) represents behavioral adaptation;
* (P_t) represents political response;
* (L_t) represents institutional adaptive capacity.

These additional variables should be introduced only when the relevant feedback mechanism cannot otherwise be represented.

---

# 5. Timing Convention

The dynamic model adopts the following within-period sequence.

## Beginning of Period (t)

The system has:

[
H_t,\quad I_t,\quad A_t,\quad E_t.
]

## Translation Stage

Institutions translate actor characteristics into outcomes:

[
Y_{i,t+1}
=========

\Phi_t(h_{i,t};I_t,E_t)
+
\varepsilon_{i,t+1}.
]

## Allocation Stage

Individual outcomes form a new allocation:

[
A_{t+1}
=======

\mathcal{G}(Y_{t+1}).
]

## Adaptation Stage

Actors and organizations update behavior:

[
B_{t+1}
=======

\mathcal{B}
\left(
B_t,
Y_{t+1},
A_{t+1},
I_t,
E_t
\right).
]

## Political Response Stage

The allocation and behavioral state generate political pressures:

[
P_{t+1}
=======

\mathcal{P}
\left(
P_t,
A_{t+1},
B_{t+1},
I_t,
E_t
\right).
]

## Institutional Update Stage

Institutions change:

[
I_{t+1}
=======

\mathcal{I}
\left(
I_t,
A_{t+1},
B_{t+1},
P_{t+1},
L_t,
E_t
\right).
]

The next period begins with the updated state.

This ordering is a modeling convention, not a claim that all real social processes follow a perfectly sequential timeline.

# 6. Dynamic Characteristic Updating

Translated outcomes may alter future actor characteristics.

A simple linear update is:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta Y_{i,t+1}
+
\xi I_t
+
\nu_{i,t+1}.
]

where:

* (\rho_h) represents persistence in the characteristic;
* (\eta) represents outcome-induced accumulation or depletion;
* (\xi) represents a direct institutional contribution;
* (\nu_{i,t+1}) represents shocks.

Substituting the translation equation gives:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta
\Phi_t(h_{i,t};I_t,E_t)
+
\xi I_t
+
\tilde{\nu}_{i,t+1}.
]

This creates a recursive link:

[
h_{i,t}
\rightarrow
Y_{i,t+1}
\rightarrow
h_{i,t+1}.
]

---

# 7. Interpretation of Characteristic Updating

Depending on the application, (h_{i,t}) may represent:

* human capital;
* wealth;
* health;
* political influence;
* social status;
* institutional knowledge;
* network access.

Translated outcomes may increase or decrease the future characteristic.

Examples include:

* earnings financing further education;
* wealth enabling access to higher-return investments;
* employment improving experience and employability;
* exclusion weakening future credentials;
* political access generating greater future influence;
* poor health outcomes reducing future labor capacity.

The updating equation must therefore be substantively interpreted rather than treated as a generic autoregression.

---

# 8. Persistence without Institutional Change

First consider fixed institutions:

[
I_{t+1}=I_t=\bar I.
]

Suppose the translation function is linear:

[
Y_{i,t+1}
=========

\alpha
+
(\beta+\delta\bar I)h_{i,t}
+
\gamma\bar I
+
\varepsilon_{i,t+1}.
]

Suppose characteristics update according to:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta Y_{i,t+1}
+
\nu_{i,t+1}.
]

Substitution yields:

[
h_{i,t+1}
=========

\left[
\rho_h
+
\eta(\beta+\delta\bar I)
\right]h_{i,t}
+
\eta(\alpha+\gamma\bar I)
+
\tilde{\nu}_{i,t+1}.
]

Define the effective persistence coefficient:

[
\kappa(\bar I)
==============

\rho_h
+
\eta(\beta+\delta\bar I).
]

Institutions therefore influence persistence even when institutions themselves do not change.

---

# 9. Stability Condition

The scalar characteristic process is locally stable when:

[
|\kappa(\bar I)|<1.
]

That is:

[
\left|
\rho_h
+
\eta(\beta+\delta\bar I)
\right|
<1.
]

If:

[
|\kappa(\bar I)|>1,
]

small initial differences may expand over time.

If:

[
\kappa(\bar I)\approx 1,
]

differences may persist for long periods.

If:

[
|\kappa(\bar I)|<|\rho_h|,
]

the institutional translation process reduces underlying persistence.

This establishes an important distinction:

> Institutions may affect not only current returns to characteristics, but also the intertemporal persistence of those characteristics.

---

# 10. Dynamic Amplification

Dynamic amplification occurs when translated advantage increases future advantage.

Suppose:

[
\eta>0
]

and:

[
\beta+\delta I_t>0.
]

Then actors with higher (h_{i,t}) receive higher outcomes, and those outcomes further increase future (h_{i,t+1}).

The recursive sequence is:

[
h_{i,t}
\uparrow
\Rightarrow
Y_{i,t+1}
\uparrow
\Rightarrow
h_{i,t+1}
\uparrow.
]

Institutions amplify this process when:

[
\delta I_t>0
]

raises the characteristic gradient.

A stronger sufficient condition for accelerating divergence is:

[
\rho_h
+
\eta(\beta+\delta I_t)

>

1.

]

This condition should be interpreted cautiously because nonlinearities, ceilings, redistribution, and shocks may prevent indefinite divergence.

---

# 11. Dynamic Compression

Dynamic compression occurs when the institutional translation structure reduces the reproduction of initial differences.

This can occur when:

[
\delta I_t<0
]

reduces the characteristic gradient, or when institutional mechanisms increase the characteristics of initially disadvantaged actors.

A compressive characteristic update may be written:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta Y_{i,t+1}
+
\chi(\bar h_t-h_{i,t})
+
\nu_{i,t+1},
]

where:

[
\chi>0
]

represents a compensatory institutional process.

Examples include:

* targeted education;
* progressive transfers;
* universal health access;
* remedial institutional support;
* equalizing credit access.

Compression occurs when the distance between actors declines:

[
|h_{i,t+1}-h_{j,t+1}|
<
|h_{i,t}-h_{j,t}|.
]

Compression of one dimension does not imply equality across all outcomes or welfare improvement.

---

# 12. Allocation Dynamics

Let the outcome allocation at (t+1) be:

[
A_{t+1}
=======

\mathcal{G}(Y_{1,t+1},\ldots,Y_{n,t+1}).
]

For a linear translation model:

[
Y_{i,t+1}
=========

\alpha
+
(\beta+\delta I_t)h_{i,t}
+
\gamma I_t
+
\varepsilon_{i,t+1}.
]

The conditional mean is:

[
\mu_{Y,t+1}
===========

\alpha
+
(\beta+\delta I_t)\mu_{H,t}
+
\gamma I_t.
]

Under independence between (H_t) and the disturbance:

[
\sigma^2_{Y,t+1}
================

(\beta+\delta I_t)^2\sigma^2_{H,t}
+
\sigma^2_{\varepsilon,t+1}.
]

Thus, institutions affect allocation by changing:

* the mean outcome;
* the translation of characteristic variance;
* the contribution of stochastic risk.

---

# 13. Evolution of Characteristic Dispersion

Suppose:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta Y_{i,t+1}
+
\nu_{i,t+1}.
]

Then:

[
h_{i,t+1}
=========

\kappa(I_t)h_{i,t}
+
c(I_t)
+
\tilde{\nu}_{i,t+1},
]

where:

[
\kappa(I_t)
===========

\rho_h+\eta(\beta+\delta I_t).
]

The variance evolves approximately as:

[
\sigma^2_{H,t+1}
================

\kappa(I_t)^2\sigma^2_{H,t}
+
\sigma^2_{\tilde{\nu},t+1},
]

assuming independence.

Institutions may therefore influence long-run heterogeneity by altering the propagation coefficient:

[
\kappa(I_t).
]

This provides a direct link between Institutional Translation and distribution dynamics.

---

# 14. Institutional Feedback from Allocation

Institutions may respond to the allocation generated by prior translation.

A simple institutional update is:

[
I_{t+1}
=======

\rho_I I_t
+
\psi Z(A_{t+1})
+
\omega_{t+1},
]

where:

* (\rho_I) represents institutional persistence;
* (Z(A_{t+1})) is a selected property of the allocation;
* (\psi) represents institutional responsiveness;
* (\omega_{t+1}) represents institutional shocks.

Possible allocation signals include:

* mean outcomes;
* inequality;
* mobility;
* unemployment;
* concentration of wealth;
* political exclusion;
* exposure to risk;
* social conflict.

The function (Z(\cdot)) must be specified for each application.

---

# 15. Corrective and Reinforcing Institutional Feedback

Institutional feedback may be corrective or reinforcing.

## Corrective Feedback

If higher inequality induces institutions that reduce amplification:

[
\frac{\partial I_{t+1}}
{\partial Z(A_{t+1})}
\cdot
\frac{\partial \delta(I_{t+1})}
{\partial I_{t+1}}
<0.
]

The institutional response weakens the mechanism generating dispersion.

## Reinforcing Feedback

If higher inequality increases the influence of advantaged actors and strengthens amplifying institutions:

[
\frac{\partial I_{t+1}}
{\partial Z(A_{t+1})}
\cdot
\frac{\partial \delta(I_{t+1})}
{\partial I_{t+1}}

> 0.
> ]

The institutional response strengthens the mechanism generating dispersion.

The sign of institutional feedback is an empirical question, not a framework assumption.

---

# 16. Political Mediation

Allocation does not usually alter institutions automatically.

Political processes mediate institutional response.

Let:

[
P_{t+1}
=======

\mathcal{P}
\left(
P_t,
A_{t+1},
B_{t+1},
I_t,
E_t
\right).
]

Institutional updating becomes:

[
I_{t+1}
=======

\mathcal{I}
\left(
I_t,
P_{t+1},
L_t,
E_t
\right).
]

This yields:

[
A_{t+1}
\rightarrow
P_{t+1}
\rightarrow
I_{t+1}.
]

Possible political channels include:

* voting;
* lobbying;
* coalition formation;
* protest;
* agenda setting;
* litigation;
* elite influence;
* bureaucratic pressure.

The Dynamic Extension should not assume that aggregate social dissatisfaction directly produces reform.

Institutional response depends on the translation of outcomes into political influence.

---

# 17. Unequal Political Translation

Political influence may itself be institutionally translated.

Let actor (i)'s political influence be:

[
p_{i,t+1}
=========

\Pi
\left(
Y_{i,t+1},
h_{i,t};
I_t^P
\right)
+
\zeta_{i,t+1},
]

where:

[
I_t^P
]

represents political institutions.

Aggregate political pressure is:

[
P_{t+1}
=======

\mathcal{K}
\left(
p_{1,t+1},
\ldots,
p_{n,t+1}
\right).
]

This means that social outcomes may affect institutional reform unequally.

Actors who receive greater economic rewards may also gain greater capacity to preserve or modify the institutional mapping.

The recursion becomes:

[
H_t
\rightarrow
Y_{t+1}
\rightarrow
P_{t+1}
\rightarrow
I_{t+1}
\rightarrow
\Phi_{t+1}.
]

This is a central possible source of institutional reinforcement.

# 18. Behavioral Adaptation

Actors respond strategically to institutional translation rules.

Let:

[
b_{i,t+1}
=========

\mathcal{B}
\left(
b_{i,t},
h_{i,t},
Y_{i,t+1},
I_t,
\mathbb{E}*t[I*{t+1}]
\right).
]

Behavioral adaptation may include:

* investment in education;
* tax avoidance;
* migration;
* credential acquisition;
* occupational switching;
* lobbying;
* informal circumvention;
* compliance;
* concealment;
* institutional arbitrage.

Behavior may alter effective characteristics:

[
\tilde h_{i,t+1}
================

\mathcal{Q}(h_{i,t+1},b_{i,t+1}),
]

or alter the effective institutional mapping:

[
\Phi_{t+1}^{E}
==============

\Phi
\left(
\cdot;
I_{t+1}^{F},
B_{t+1}
\right).
]

# 19. Formal and Effective Institutional Dynamics

Let:

* (I_t^F) denote formal institutional rules;
* (I_t^E) denote effective institutional practice.

Formal institutional updating may be:

[
I_{t+1}^{F}
===========

\mathcal{I}^{F}
\left(
I_t^F,
P_{t+1},
E_t
\right).
]

Effective institutional updating may be:

[
I_{t+1}^{E}
===========

\mathcal{I}^{E}
\left(
I_{t+1}^{F},
I_t^E,
B_{t+1},
L_t,
E_t
\right).
]

The translation function then becomes:

[
Y_{i,t+1}
=========

\Phi
\left(
h_{i,t};
I_t^F,
I_t^E,
E_t
\right)
+
\varepsilon_{i,t+1}.
]

Formal reform may occur while effective translation changes only gradually:

[
I_{t+1}^{F}\neq I_t^F,
]

but:

[
I_{t+1}^{E}\approx I_t^E.
]

This produces implementation lag.

# 20. Institutional Adaptation and Erosion

Behavioral responses may reduce the effectiveness of an intervention.

Suppose a formal intervention initially changes the translation coefficient from:

[
\delta_0
]

to:

[
\delta_1.
]

Actors then adapt, causing the effective coefficient to evolve:

[
\delta_{t+1}^{E}
================

\rho_\delta\delta_t^{E}
+
(1-\rho_\delta)\delta_t^{F}
---------------------------

\theta a_t,
]

where:

* (a_t) represents avoidance, circumvention, or strategic adaptation;
* (\theta>0) represents the erosive effect of adaptation.

The intervention effect may decline over time even if the formal rule remains unchanged.

This formalizes the proposition that public interventions may lose effectiveness through endogenous adaptation.

---

# 21. Institutional Learning

Institutional learning may counteract erosion.

Let:

[
L_t
]

represent institutional adaptive capacity.

The effective institutional update may be:

[
I_{t+1}^{E}
===========

I_t^E
+
L_t
\left[
I_t^{Target}
------------

I_t^E
\right]
-------

\theta a_t
+
\omega_{t+1}.
]

Higher (L_t) increases the capacity to:

* detect implementation failure;
* revise procedures;
* respond to avoidance;
* incorporate new information;
* preserve institutional effectiveness.

Adaptive capacity may itself evolve:

[
L_{t+1}
=======

\mathcal{L}
\left(
L_t,
\text{feedback}_t,
\text{resources}_t,
\text{legitimacy}_t
\right).
]

The inclusion of (L_t) is justified only when institutional learning is central to the application.

---

# 22. Endogenous Translation Function

The translation function may evolve even when the nominal institutional variable changes little.

Write:

[
\Phi_t
======

\Phi(\cdot;\theta_t),
]

where:

[
\theta_t
]

is the vector of effective translation parameters.

For the linear model:

[
\theta_t
========

(\alpha_t,\beta_t,\gamma_t,\delta_t).
]

Parameter evolution may be represented by:

[
\theta_{t+1}
============

\Psi
\left(
\theta_t,
A_{t+1},
B_{t+1},
P_{t+1},
L_t,
E_t
\right)
+
\upsilon_{t+1}.
]

The translation equation becomes:

[
Y_{i,t+1}
=========

\alpha_t
+
\beta_t h_{i,t}
+
\gamma_t I_t
+
\delta_t h_{i,t}I_t
+
\varepsilon_{i,t+1}.
]

The dynamic object is no longer only (I_t).

The mapping itself evolves.

# 23. Distinguishing Institutional Change from Mapping Change

A change in (I_t) and a change in (\Phi_t) are not identical.

## Institutional Change

A rule, procedure, or enforcement arrangement changes:

[
I_{t+1}\neq I_t.
]

## Translation Change

The relationship between characteristics and outcomes changes:

[
\Phi_{t+1}\neq\Phi_t.
]

It is possible that:

[
I_{t+1}\neq I_t
]

while:

[
\Phi_{t+1}\approx\Phi_t,
]

because the reform is ineffective.

It is also possible that:

[
I_{t+1}=I_t
]

while:

[
\Phi_{t+1}\neq\Phi_t,
]

because behavior, interpretation, implementation, technology, or enforcement changed.

Empirical analysis should therefore examine the translation mapping directly whenever possible.

---

# 24. Path Dependence

The current outcome may depend not only on the current institutional state but also on institutional history.

A history-dependent translation function is:

[
Y_{i,t+1}
=========

\Phi
\left(
h_{i,t};
I_t,
I_{t-1},
\ldots,
I_{t-k},
E_t
\right)
+
\varepsilon_{i,t+1}.
]

Alternatively, define an institutional stock:

[
J_{t+1}
=======

\rho_JJ_t
+
(1-\rho_J)I_t.
]

The outcome then depends on:

[
Y_{i,t+1}
=========

\Phi(h_{i,t};I_t,J_t,E_t)
+
\varepsilon_{i,t+1}.
]

The institutional stock may represent:

* accumulated legitimacy;
* precedent;
* organizational routines;
* legal interpretation;
* administrative experience;
* public expectations.

This allows identical current formal institutions to produce different outcomes because their histories differ.

---

# 25. Hysteresis

Hysteresis occurs when reversing a formal institutional change does not restore the prior translation mapping.

Suppose:

[
I_t:
I^0\rightarrow I^1\rightarrow I^0.
]

Hysteresis exists when:

[
\Phi_{t+2}(\cdot;I^0)
\neq
\Phi_t(\cdot;I^0).
]

Possible causes include:

* accumulated actor adaptation;
* changed expectations;
* organizational restructuring;
* irreversible investment;
* weakened institutional legitimacy;
* altered political coalitions;
* network reconfiguration.

Hysteresis is stronger than ordinary persistence because the path itself affects the resulting mapping.

---

# 26. Multiple Equilibria

A recursive translation system may possess multiple stable states.

Consider:

[
h_{t+1}
=======

\mathcal{H}(h_t,I_t),
]

[
I_{t+1}
=======

\mathcal{I}(I_t,A_{t+1}),
]

with:

[
A_{t+1}
=======

\mathcal{G}
\left(
\Phi(h_t;I_t)
\right).
]

An equilibrium satisfies:

[
h^\ast
======

\mathcal{H}(h^\ast,I^\ast),
]

[
I^\ast
======

\mathcal{I}
\left(
I^\ast,
\mathcal{G}(\Phi(h^\ast;I^\ast))
\right).
]

Different initial conditions may converge to different equilibria.

For example, the system may exhibit:

* a high-opportunity, high-capability equilibrium;
* a low-opportunity, low-capability equilibrium;
* an inclusive institutional equilibrium;
* an extractive institutional equilibrium.

The existence of multiple equilibria must be demonstrated rather than assumed.

---

# 27. Regime Change

Institutional change may be gradual or discontinuous.

Let (Z_t) represent accumulated pressure:

[
Z_{t+1}
=======

\rho_Z Z_t
+
q(A_{t+1},P_{t+1},E_t).
]

A regime shift occurs when:

[
Z_t\geq Z^\ast.
]

Then:

[
I_{t+1}
=======

\begin{cases}
I_t, & Z_t<Z^\ast,\
I^{New}, & Z_t\geq Z^\ast.
\end{cases}
]

The translation function changes accordingly:

[
\Phi_{t+1}
==========

\Phi(\cdot;I^{New}).
]

This structure may represent:

* constitutional reform;
* revolution;
* legal transformation;
* major administrative reorganization;
* abrupt policy reversal.

Threshold models should be used only when the institutional process plausibly contains a discontinuity.

---

# 28. External Shocks

External conditions may affect all parts of the dynamic system.

Let:

[
E_{t+1}
=======

\mathcal{E}(E_t)
+
\epsilon^E_{t+1}.
]

External shocks may alter:

* actor characteristics;
* institutional capacity;
* political coalitions;
* behavioral strategies;
* the translation function itself.

A general dynamic representation is:

[
S_{t+1}
=======

\mathcal{T}
\left(
S_t,
E_t,
\varepsilon_{t+1}
\right).
]

Examples include:

* technological change;
* war;
* pandemic;
* demographic transition;
* trade shock;
* environmental disaster.

The model should distinguish external shocks from endogenous institutional change.

# 29. Luck and Stochastic Accumulation

Stochastic outcomes may become embedded in future characteristics.

Suppose:

[
Y_{i,t+1}
=========

\Phi_t(h_{i,t};I_t)
+
\varepsilon_{i,t+1},
]

and:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta Y_{i,t+1}.
]

Then:

[
h_{i,t+1}
=========

\rho_h h_{i,t}
+
\eta\Phi_t(h_{i,t};I_t)
+
\eta\varepsilon_{i,t+1}.
]

A temporary random shock:

[
\varepsilon_{i,t+1}
]

may therefore have persistent consequences.

Institutions condition the degree to which luck becomes durable advantage or disadvantage.

Examples include:

* bankruptcy protection;
* social insurance;
* inheritance;
* access to recovery credit;
* educational remediation;
* health coverage.

This connects Institutional Translation with the framework’s treatment of luck.

# 30. Survivorship and Observed Dynamics

Observed populations may exclude actors, organizations, or institutions that failed to survive prior transitions.

Let:

[
R_{i,t+1}\in{0,1}
]

indicate continued observation or participation.

Survival may depend on:

[
\Pr(R_{i,t+1}=1)
================

\mathcal{R}
\left(
h_{i,t},
Y_{i,t+1},
I_t,
E_t
\right).
]

The observed outcome distribution is then:

[
p
\left(
Y_{t+1}
\mid
R_{t+1}=1
\right),
]

not the full underlying distribution:

[
p(Y_{t+1}).
]

Institutional translation estimates may therefore be biased if institutions affect both outcomes and survival.

This is particularly important in historical analysis, organizational studies, entrepreneurship, migration, and long-run mobility research.

The mapping itself evolves.

The project should establish Case 1 before advancing to Cases 2 and 3.

# 34. Dynamic Propositions

## Proposition 1 — Institutionally Conditioned Persistence

The persistence of actor characteristics depends on the institutional translation gradient:

[
\kappa(I_t)
===========

\rho_h+\eta(\beta+\delta I_t).
]

---

## Proposition 2 — Outcome-Induced Heterogeneity

Institutions can change future heterogeneity even when they do not directly alter initial characteristic distributions.

---

## Proposition 3 — Recursive Amplification

An amplifying translation rule combined with positive outcome accumulation can generate increasing dispersion over time.

---

## Proposition 4 — Recursive Compression

A compressive translation rule or compensatory characteristic update can reduce the persistence of initial differences.

---

## Proposition 5 — Allocation-to-Institution Feedback

Institutional states may change in response to distributions generated by prior institutional translation.

---

## Proposition 6 — Unequal Reform Influence

Where economic or social outcomes are translated into unequal political influence, advantaged actors may disproportionately shape future institutions.

---

## Proposition 7 — Implementation Divergence

Formal institutional reform does not necessarily change the effective translation function.

---

## Proposition 8 — Adaptive Erosion

Behavioral adaptation may reduce the effectiveness of a formally unchanged intervention.

---

## Proposition 9 — Institutional Learning

Systems with greater adaptive capacity should correct implementation drift more effectively.

---

## Proposition 10 — Path Dependence

Identical current institutional rules may produce different mappings when institutional histories differ.

---

## Proposition 11 — Persistent Luck

Temporary stochastic shocks may have durable consequences when outcomes feed into future characteristics.

---

## Proposition 12 — Selective Observation

Institutionally conditioned survival may cause observed transition dynamics to differ from the underlying process.

# 35. Testable Implications

The dynamic model produces several empirical implications.

## Persistence Gradients

Intergenerational or interperiod persistence should differ across institutional regimes.

## Reform Timing

The immediate and long-run effects of institutional reform may differ.

## Effect Decay

Intervention effects may decline as actors adapt.

## Implementation Lags

Changes in formal rules may precede changes in outcomes.

## Distributional Feedback

Periods of increasing concentration may be followed by identifiable institutional reinforcement or correction.

## Historical Dependence

The effect of a current institution may depend on the duration and sequence of prior institutions.

## Shock Persistence

Similar shocks may produce different long-term outcomes under different institutional systems.

---

# 36. Identification Challenges

Dynamic Institutional Translation introduces additional identification problems.

## Simultaneity

Institutions affect outcomes, while outcomes affect institutions.

## State Dependence

Current outcomes depend on prior outcomes and characteristics.

## Unobserved Heterogeneity

Persistent unobserved actor traits may mimic recursive translation.

## Institutional Anticipation

Actors may respond before formal institutional change.

## Time-Varying Confounding

External conditions may jointly alter institutions and outcomes.

## Measurement Drift

Institutional indicators may change meaning through time.

## Survivor Selection

Observed actors may be a selected subset of those exposed to prior translation.

## Functional Instability

The same parameterization may not apply across regimes or historical periods.

A dynamic empirical strategy must address these issues explicitly.

# 38. Simulation Program

Simulation is useful before empirical estimation because the recursive system may generate unintuitive consequences.

The initial simulation should vary:

* (\rho_h): characteristic persistence;
* (\eta): outcome-to-characteristic accumulation;
* (\delta): translation strength;
* (\rho_I): institutional persistence;
* (\psi): institutional responsiveness;
* shock variance;
* initial characteristic dispersion.

The simulation should examine:

* convergence;
* divergence;
* stable inequality;
* institutional correction;
* institutional reinforcement;
* reform effects;
* effect erosion;
* sensitivity to initial conditions.

Simulation results should not be treated as empirical validation.

They are tools for deriving implications and identifying parameter regions.

# 39. Benchmark Dynamic Models

The dynamic extension should be compared with simpler models.

## Benchmark A — Static Translation

[
Y_{t+1}
=======

\Phi(H_t;I_t).
]

No recursive updating occurs.

## Benchmark B — Characteristic Persistence Only

[
H_{t+1}
=======

\rho_H H_t+\nu_{t+1}.
]

Institutions do not affect persistence.

## Benchmark C — Exogenous Institutional Change

[
I_{t+1}
=======

\rho_I I_t+\omega_{t+1}.
]

Institutions evolve independently of allocations.

## Benchmark D — Additive Institutional Feedback

Institutions shift outcome levels but do not alter characteristic gradients.

The dynamic translation model adds value only if institutional conditioning and recursion produce distinct explanatory or predictive gains.

# 40. Falsification Criteria

The dynamic extension should be weakened if:

* translated outcomes do not materially affect future actor characteristics;
* persistence rates do not differ across institutional environments;
* allocation changes do not predict institutional responses after accounting for confounders;
* apparent institutional feedback disappears when political mediation is modeled;
* formal and effective institutions do not meaningfully diverge;
* intervention effects do not change as behavior adapts;
* path-history variables add no explanatory value;
* stochastic shocks do not persist differently across institutions;
* recursive models do not outperform static benchmarks;
* dynamic parameters are too unstable to support interpretable mechanisms.

The strong recursive claim should be rejected within a domain when outcomes do not feed back into future characteristics or institutional conditions in a detectable way.

---

# 41. Scope Conditions

The dynamic extension is most appropriate where:

* outcomes accumulate into future resources or capabilities;
* institutional rules persist across multiple periods;
* actors adapt strategically;
* allocations affect political or administrative decisions;
* implementation differs from formal design;
* institutional learning is possible;
* historical sequence matters.

It may be less appropriate where:

* outcomes are one-time and nonaccumulative;
* institutions are fully exogenous;
* time horizons are very short;
* actor turnover eliminates persistence;
* physical constraints dominate institutional feedback;
* institutional change is too rare to observe.

---

# 42. Positive–Normative Separation

Dynamic compression is not automatically desirable.

Dynamic amplification is not automatically undesirable.

A system may produce:

* higher average development and greater dispersion;
* lower dispersion and lower average outcomes;
* greater mobility but higher risk;
* greater institutional stability but reduced adaptability.

The dynamic model describes these transitions.

Normative evaluation requires a separate welfare function:

[
W_t
===

W(D_t,A_t,R_t,\ldots).
]

The welfare function must not be embedded implicitly in the transition equations.

# 45. Development Judgment

The static translation model can be extended into a coherent recursive system without expanding immediately to the full conceptual state.

The minimum dynamic logic is:

[
H_t
\rightarrow
Y_{t+1}
\rightarrow
H_{t+1}
]

under an institutionally conditioned translation rule.

A second layer adds:

[
Y_{t+1}
\rightarrow
A_{t+1}
\rightarrow
I_{t+1}.

A third layer adds:

[
A_{t+1}
\rightarrow
B_{t+1},P_{t+1},L_{t+1}

This layered approach preserves parsimony while allowing the model to explain how institutional translation may generate:

* persistence;
* cumulative advantage;
* cumulative disadvantage;
* compression;
* intervention decay;
* institutional reinforcement;
* institutional correction;
* path dependence;
* regime change.

The dynamic extension therefore establishes the bridge from a static institutional interaction to a recursive theory of social-system evolution.
