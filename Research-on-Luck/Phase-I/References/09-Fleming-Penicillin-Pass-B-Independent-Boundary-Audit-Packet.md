## Status

**Audit instrument FLEM-01-B-AUDIT, Version 1.1 — RC2 re-audit edition, 20 July 2026**

This instrument is for an independent reviewer of the [Pass B Version 1.0-RC2 coder packet](07-Fleming-Penicillin-Bounded-Pass-B-Coder-Packet.md) and its [claim-level evidence inventory](08-Fleming-Penicillin-Pass-B-Claim-Level-Evidence-Inventory.md). The reviewer audits packet construction. The reviewer does **not** code the Fleming opportunities, adjudicate Pass B, or decide what the historical evidence ultimately proves.

## Independence Requirement

The reviewer should not have:

- built or revised the Pass B packet or inventory;
- completed a Fleming Pass A or Pass B coding record;
- participated in the Pass A adjudication;
- seen an evidence-builder's proposed Pass B classifications; or
- been instructed to approve the packet.

Prior general knowledge of penicillin is permitted but must be disclosed. The audit concerns documentary fidelity and protocol integrity, not historical naïveté.

## Audit Standard

The packet is ready to freeze only if a reasonable independent coder could apply its rules using the supplied primary sources without:

- relying on a missing or partial document;
- receiving an unsupported builder interpretation as fact;
- confusing printed pages with PDF pages;
- attributing later work to the wrong focal system;
- using later checkpoints to determine earlier codes;
- mistaking planned production for realized output;
- or relying on retrospective history for a core inference.

## Severity Definitions

| Severity | Definition | Release consequence |

| **Critical** | Wrong or incomplete source, altered candidate or horizon, unsupported core claim, missing 01D component, or outcome leakage that compromises a checkpoint | Reject RC1; substantive revision required |

| **Minor** | Typographical, formatting, or locator problem unlikely to change coding | May issue RC2 after correction; reviewer confirms disposition |
