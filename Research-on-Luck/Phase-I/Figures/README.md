# Figures

## Purpose

The **Figures/** directory contains shared conceptual visualizations for **Research on Luck**. Figures should clarify relationships difficult to communicate through prose or tables and should not substitute for formal specification.

## Figure Standards

Each figure should:

- communicate a defined analytical relationship;
- identify whether it is conceptual, formal, empirical, or illustrative;
- distinguish analytical layers from temporal or causal sequences;
- avoid implying validated causation through layout alone;
- state its version and status;
- and link to a Markdown explanation.

A regenerated PNG should preserve four coequal primitives, nonmandatory layered relationships, recursive feedback, and the distinction among luck potential, realization, and attribution.
