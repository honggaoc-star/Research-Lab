# Prediction–Attribution Conjugacy in Adaptive Decision Problems

**Version:** 1.0<br>
**Date:** October 2026<br>
**Author:** Honggao Cao

This paper examines adaptive decision problems in which decision makers form structural accounts, make prospective predictions, act, and learn from subsequent outcomes. It describes when prediction and attribution become reciprocally linked, separates that conjugate core from surrounding responsive dynamics, and shows how the framework can distinguish ordinary model failure from structural change and success-induced signal decay.
